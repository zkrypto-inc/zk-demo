# zkdemo-v2

zkrypto 제품 데모 프론트엔드입니다. 제품별 시나리오 화면을 제공하고, 현재는 다음 백엔드와 직접 연동합니다.

- `zkWallet`: `zkwallet-adapter`를 통해 wallet-api 지갑/키/서명 흐름 실행
- `zkPoL`: `zk-pol` manager/event-generator 및 네이티브 대시보드 연동
- `zkTransfer`, `zkPasskey`: 현재 시나리오 UI 중심 데모

처음 실행하거나 배포할 때는 [RUNBOOK.md](RUNBOOK.md)를 그대로 따라가면 됩니다.
